# مؤسسة الغولي لبيع وتسويق الأسمنت

تطبيق ومنصة إلكترونية لبيع وتسويق الأسمنت وتوصيله للعملاء.

## التقنيات

| الطبقة | التقنية |
|---|---|
| Backend | Node.js + Express |
| Database | PostgreSQL (Supabase) |
| ORM | Prisma |
| Mobile | Flutter |
| Admin | React + Vite |

## المصانع والأنواع

| المصنع | الرمز | بورتلاندي | مقاوم | تشطيبات |
|---|---|---|---|---|
| عمران | AMR | نعم | - | - |
| باجل | BAJ | نعم | - | - |
| البرح | BAR | نعم | - | - |
| الوطنية | WAT | نعم | نعم | نعم |
| حضرموت | HAD | نعم | نعم | نعم |
| النهضة | NAH | نعم | - | - |
| الوحدة | WAH | نعم | - | - |
| إعمار اليمن | EMA | نعم | - | نعم |

## أنواع الأسمنت

- OPC - بورتلاندي عادي (أخضر)
- SRC - مقاوم للكبريتات (أحمر)
- WPC - أبيض للتشطيبات (أبيض)
